## 🚀 Execution & Local Development

### Option 1: Run via Streamlit
```bash
pip install -r requirements.txt
streamlit run app.py
```
Open **http://localhost:8501** in your browser.

### Option 2: Standalone Zero-Dependency Runner
```bash
python3 standalone_runner.py
```
Access directly at **http://localhost:8501**.
